# Official collection endpoint repairs

## Verified without paid model requests

The declared OpportunityRadar user agent, public HTTPS checks and robots.txt
enforcement were used for all probes. Six official endpoints were readable:

- ODI: https://careers.odi.org/ (linked by the official careers page).
- Chatham House: https://careers.chathamhouse.org/jobs (official recruitment site).
- SEI: https://www.sei.org/people/jobs/ (current opportunity directory).
- ECPR: https://ecpr.eu/JointSessions (current political science workshop page).
- OECD: https://careers.smartrecruiters.com/OECD (official recruitment provider).
- DAAD EPOS: official scholarship database and linked deadline PDF.

The OECD Posting API endpoint was NOT used: its robots.txt disallowed this
collector. Readable recruitment HTML supplies the job links instead.
Readability is not a claim that every advertised opportunity is currently open
or eligible: detail evidence and extraction validation still apply.

## Changes

- Replace obsolete or blocked landing-page URLs with the verified current
  official entry points, preserving the institutional entry for provenance.
- Try only configured official fallback URLs, at most three attempts per source.
  Apply the same registered-domain, HTTPS and robots checks to every attempt.
- Record attempted and actually fetched entries in collection diagnostics.
- Allow SEI's /people/jobs/ detail pages while excluding staff biographies.
- Exclude recruitment-process, terms, registration-of-interest and navigation
  links from the detail queue.
- Extract ECPR event and DAAD scholarship programme content before ancillary
  links. For DAAD, keep the official deadline/programme attachments in the queue
  instead of generic funding help pages.
- Prevent UN youth/event discovery from reintroducing UN internships.

## Cost and completeness

Weekly scheduling and gpt-4.1-mini remain unchanged. A full workflow run checks
all registered source entries. Paid extraction remains bounded to 7 model
requests, including indexed discovery, and 18 changed detail/programme pages.
Deferred pages and inaccessible sources remain explicitly recorded; a complete
workflow run is not an exhaustive crawl of every institution.

Do not bypass 403s, CAPTCHAs, login restrictions or robots prohibitions. Sources
that still lack an allowed public entry require a publisher feed/API, a verified
public application endpoint, or future user-supplied/subscribed source material.

41 automated regression tests pass locally before deployment.
